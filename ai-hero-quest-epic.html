HOW TO PLAY

1. Build a program with the command buttons.

2. RUN AI CODE executes the list. STEP runs one command.

3. FORWARD / BACK move facing direction. TURN rotates in place.

4. ATTACK hits the tile ahead. SHIELD blocks the next trap step.

5. COLLECT GEM picks up a gem on your tile. Gems also auto-collect when you walk onto them.

6. ADD LOOP repeats your current program N times.

7. Fewer commands = more stars. Reach the portal with all gems and enemies cleared.

Keys: Arrows add move/turn · A attack · S shield · C collect · Space/Enter run · R reset · P pause · M mute
